# Interactive 3D Learning Lab

An interactive 3D educational web application
built using HTML, CSS, JavaScript, and Babylon.js.

## Features

- Interactive 3D computer workstation
- Rotatable and zoomable camera
- Desk, monitor, keyboard, and mouse
- Three programming books: HTML, CSS, JavaScript
- Clickable educational information panels
- Book hover effects
- Dynamic book labels
- Reusable JavaScript functions

## Technologies

- HTML5
- CSS3
- JavaScript
- Babylon.js
